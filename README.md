# 💼 Institutional Wealth & Mutual Fund Analytics Dashboard

An interactive portfolio analytics tool built with Python and Streamlit, designed to evaluate mutual fund performance, quantitative risk metrics, and forward wealth projections for wealth management clients.

🚀 **Live Interactive App:** [Click Here to Open Dashboard](https://mutual-fund-dashboard-ugekw6qtgxgrmtpcpau87z.streamlit.app/)

### Key Features
* **Quantitative Risk Metrics:** Calculates Sharpe Ratio, Beta, CAGR, and Max Drawdown relative to market benchmarks.
* **Monte Carlo Simulations:** Models 1,000 stochastic portfolio wealth paths over 1–10 year client planning horizons.
* **Crisis Stress-Testing:** Replays portfolio drawdowns across major market shocks (e.g., 2020 COVID crash, 2022 rate hikes).
* **Flexible Asset Coverage:** Includes pre-configured options for 20+ major mutual funds (including Allspring / Wells Fargo legacy funds) and custom ticker inputs.
